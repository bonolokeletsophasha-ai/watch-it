# Watch-It: Movie Watchlist API

A RESTful backend API for managing a movie watchlist, built with Node.js and Express. This project uses an in-memory array rather than a database, so changes reset when the server restarts.

## Technologies

- Node.js
- Express.js
- JavaScript
- Postman or Thunder Client for API testing

## Getting started

1. Install Node.js.
2. Clone this repository and open its folder in a terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

   For development with automatic restarts:

   ```bash
   npm run dev
   ```

The API runs at `http://localhost:3000` by default. Set the `PORT` environment variable to use another port.

## Movie shape

Every movie contains:

- `id`: unique integer generated by the API
- `title`: non-empty string
- `genre`: non-empty string
- `year`: integer release year
- `watched`: boolean (`true` or `false`)

## Endpoints

| Method | Endpoint | Purpose |
| --- | --- | --- |
| GET | `/` | API welcome message |
| GET | `/api/movies` | Retrieve all movies |
| GET | `/api/movies/:id` | Retrieve one movie |
| POST | `/api/movies` | Create a movie |
| PUT | `/api/movies/:id` | Replace a movie's editable fields |
| DELETE | `/api/movies/:id` | Delete a movie |

## Example request body

Use the following JSON with `POST /api/movies` or `PUT /api/movies/:id`:

```json
{
  "title": "Interstellar",
  "genre": "Science Fiction",
  "year": 2014,
  "watched": false
}
```

For POST and PUT, send the body as JSON with the header `Content-Type: application/json`. PUT requires all four editable fields.

## Status codes

- `200 OK`: successful read, update, or delete
- `201 Created`: movie created
- `400 Bad Request`: invalid ID, malformed JSON, or invalid movie data
- `404 Not Found`: movie or endpoint does not exist
- `500 Internal Server Error`: unexpected server error

## Testing checklist

Test the following requests in Postman or Thunder Client:

1. `GET http://localhost:3000/api/movies`
2. `GET http://localhost:3000/api/movies/1`
3. `GET http://localhost:3000/api/movies/999` (expect 404)
4. `POST http://localhost:3000/api/movies` with the example JSON (expect 201)
5. Copy the returned ID and GET that movie
6. `PUT http://localhost:3000/api/movies/1` with a complete JSON body (expect 200)
7. GET movie 1 again to verify the changes
8. `DELETE http://localhost:3000/api/movies/1` (expect 200)
9. GET movie 1 again (expect 404)
10. Try updating or deleting a nonexistent ID (expect 404)

Take screenshots of successful GET-all, GET-one, POST, PUT, DELETE, and at least one unsuccessful request for your project evidence.

## Request flow

Client → Route → Controller → In-memory movie array → JSON response
